# 🇮🇳 India General Election Results 2024 – Power BI Dashboard

## 📊 Project Overview

The **India General Election Results 2024 Dashboard** is an interactive Power BI project designed to analyze election results at the **national, state, and constituency levels**.

The dashboard provides insights into seat distribution, alliance performance, winning candidates, political parties, vote counts, vote margins, and state-wise election results.

The project is designed to make election data easier to explore and understand through interactive visualizations, filters, maps, KPIs, drill-through functionality, and detailed tables.

---

## 🎯 Project Objectives

* Analyze the overall performance of major political alliances.
* Compare **NDA, I.N.D.I.A., and Independent & Other Parties**.
* Analyze election results at the state level.
* Explore constituency-wise winning candidates and parties.
* Compare candidate votes and winning margins.
* Provide interactive and user-friendly election data exploration.
* Enable users to drill through from high-level results to detailed constituency data.

---

# 📌 Dashboard Pages

## 1️⃣ Overview Analysis

The Overview Analysis dashboard provides a high-level view of the 2024 General Election results.

### Key KPIs

* Total seats won by NDA
* NDA percentage of total seats
* Total seats won by I.N.D.I.A.
* I.N.D.I.A. percentage of total seats
* Seats won by Independent & Other Parties
* Percentage of seats won by Independent & Other Parties

### Features

* NDA alliance party-wise seat analysis
* I.N.D.I.A. alliance party-wise seat analysis
* Party logos and seat counts
* Interactive grid views using bookmarks

---

## 2️⃣ State Demographic Analysis

This dashboard provides a **state-wise and constituency-wise analysis** of election results.

### Key Analysis

* Total seats by state
* Majority alliance by state
* NDA seats by state
* I.N.D.I.A. seats by state
* Winning candidate by constituency
* Winning party by constituency
* Total votes
* Winning margin

### Visualizations

* State Map
* Bubble Map
* Interactive tooltips
* Drill-through details

The bubble map represents individual constituencies and uses different categories to distinguish NDA, I.N.D.I.A., and Other seats.

---

## 3️⃣ Political Landscape by State

This dashboard allows users to select a particular state and analyze its political landscape.

### Key Features

* State selection using filters
* NDA seat count
* I.N.D.I.A. seat count
* Independent & Other Parties seat count
* State constituency map
* Party-wise result grid
* Party-wise seat share

### Visualization

A **Donut Chart** is used to represent the percentage share of seats won by each party within the selected state.

---

## 4️⃣ Constituency Analysis

The Constituency Analysis dashboard provides detailed information about a selected constituency.

### Primary KPIs

* Total Votes
* Total EVM Votes
* Total Postal Votes
* Total Candidates

### Candidate Performance

#### 🥇 Winning Candidate

* State
* Candidate Name
* Party Name
* Total Votes
* Vote Share %

#### 🥈 Runner-up Candidate

* State
* Candidate Name
* Party Name
* Total Votes
* Vote Share %

#### 🥉 2nd Runner-up Candidate

* State
* Candidate Name
* Party Name
* Total Votes
* Vote Share %

---

## 5️⃣ Details Grid

The Details Grid provides a detailed tabular view of constituency-level election results.

### Fields Included

| Field               | Description                             |
| ------------------- | --------------------------------------- |
| Constituency Name   | Name of the constituency                |
| Winning Candidate   | Candidate who won the election          |
| Runner-Up Candidate | Candidate with the second-highest votes |
| Party Name          | Winning political party                 |
| Party Alliance      | NDA, I.N.D.I.A., or Independent         |
| EVM Votes           | Votes received through EVM              |
| Postal Votes        | Postal ballot votes                     |
| Total Votes         | EVM + Postal Votes                      |
| Margin              | Difference between winner and runner-up |

### Interactive Features

* Drill-through from other dashboards
* Detailed constituency-level analysis
* Data export to Excel
* Show All Data button using bookmarks

# 🚀 How to Use

1. Download the `.pbix` Power BI file.
2. Open the file using **Microsoft Power BI Desktop**.
3. Use the navigation buttons on the Landing Page.
4. Apply filters to explore different states and constituencies.
5. Use drill-through functionality for detailed analysis.
6. Explore the Details Grid for constituency-level information.
